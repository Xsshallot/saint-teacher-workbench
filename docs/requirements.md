# SAINT · 超级教师工作台 · 需求文档（v0.1）

> 整理自教师口述需求（2026-10-21）。本文件是产品共识的 single source of truth。

## 1. 一句话定位

**一套开源的"教师个人数据中枢"**：一个网站工作台 + 两个 Skill（搭建引导 Skill、工作台专属 Skill）+ 定时数据同步。任何教师（尤其是用 ZCode 等 AI 智能体的教师）通过 Skill 引导，不需要自己开发，就能从开源模板拉起一个属于自己的工作台，把自己的腾讯问卷 / 腾讯文档 / 腾讯会议（辅以飞书）数据自动同步进来，实现学员跟进、进度追踪、备课辅助；并且部署完成后会**自动生成这个工作台的专属 Skill**，让任何 AI 智能体可以直接查询和解读工作台里的数据。

**SAINT** = **S**uper **AI** **N**etworked **T**eacher（"圣者/导师"意象）。仓库名：`saint-teacher-workbench`。

核心设计理念：
1. **不是只做一个人的产品，而是做一个可复刻的开源模板 + Skill**——别人拿来就能用。
2. **数据格式全部标准化**——别人按规范传数据，网站和专属 Skill 都能直接读懂。

## 2. 产品构成：三层结构

```
腾讯问卷 ──┐
腾讯文档 ──┤  连接器 + 每日定时同步        ┌──────────────┐
腾讯会议 ──┼───────────────────────────▶ │ 本地数据层     │──▶ 工作台网站（看板）
飞书问卷  ─┤   （增量同步，有新就收）        │ （标准数据契约）│        │
飞书文档  ─┘                              └──────────────┘        ▼
                                                ▲            只读数据接口（API）
                                                │                  │
                          Skill A（搭建引导）──── scaffolding        ▼
                                                │          Skill B（部署后自动生成）
                                                │                  │
                                                                    ▼
                                                        任何 AI 智能体 / 其他 AI 工具
                                                  （"最近学员怎么样？""下节课备什么？"）
```

- **第①层 开源网站模板**：空框架 + Mock 数据，不含真实学员数据，GitHub 开源。
- **第②层 Skill A（搭建引导，给人用）**：检查连接器 → 拉模板 → 配数据源 → 建定时任务 → 首次同步验收 → 生成 Skill B。
- **第③层 Skill B（工作台专属，给 AI 用，自动生成）**：标准化描述工作台 API 与数据契约，挂到任何智能体即可自然语言查询。

## 3. 用户角色与旅程

| 角色 | 干什么 |
|---|---|
| 模板作者 | 开发框架、开源、维护 Skill A 与规范文档 |
| 复刻教师 | 被 Skill A 引导 → 配连接器 → 拉模板 → 同步数据 → 拿到 Skill B |
| AI 智能体 | 挂载 Skill B，替教师查询、解读、给建议 |

**目标体验**：对 AI 说"我想搭一个超级教师工作台" → Skill A 启动 → … → 数据同步完成 → 网站可看 → 自动生成专属 Skill → 每天数据自动更新，随时可问 AI。

## 4. 核心数据域

| # | 数据域 | 内容 | 主要来源 | 落地表 |
|---|---|---|---|---|
| 1 | 学员档案 | 个人信息、背景 | 问卷 | stu_* |
| 2 | 课程与进度 | 讲课进度、每节课主题 | 教师维护 + 会议关联 | crs_* |
| 3 | 会议记录 | 会议信息、纪要 | 腾讯会议 | mtg_* |
| 4 | 课后反馈/下节课愿望 | 想学什么 | 问卷 | fbk_* |
| 5 | 作业/任务跟进 | 提交状态、跟进记录 | 问卷、文档 | asg_* |
| 6 | 同步元数据 | 数据源、任务、日志 | 系统 | syn_* |

> 现状：学员信息存量在飞书（已通过 local-import 连接器先行接入）；后续主线是腾讯问卷/文档/会议，飞书降为兼容渠道。

## 5. 网站页面（v0.1 已实现）

| 页面 | 内容 |
|---|---|
| 总览 Dashboard | 指标卡（学员数、待跟进、课程进度、愿望数）+ 提交趋势图 + 愿望主题聚类 + 待跟进名单 |
| 学员列表 / 详情 | 搜索筛选、主攻方向；详情页 360° 画像 + 成长时间线 + 作业 + 愿望 |
| 课程与会议 | 课程进度轴（18 课次）+ 会议记录（含纪要摘要） |
| 作业任务 | 作业卡片（提交率/迟交）+ 提交明细 |
| 反馈墙 | 下节课愿望按主题聚类展示 |
| 设置 | 数据源状态、同步任务与日志、Skill B 生成入口 |

**拓展功能（规划）**：风险预警灯（连续缺勤/未交标红）、备课助手（聚合愿望生成大纲）、周报/结课报告一键生成、全局搜索。

## 6. 技术决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| 命名 | SAINT | 用户指定 |
| 技术栈 | Node ≥22.5（零依赖 node:sqlite）+ React/Vite/Tailwind | 轻量、个人本地跑、`npm start` 即用 |
| 模板参考 | cruip Mosaic Lite（仅视觉参考，自研实现） | 规避 GPL v3，保持 MIT |
| 存储 | SQLite（data/saint.db） | 单文件、免安装、随目录迁移 |
| v1 数据源 | 先 local-import（存量采集），腾讯系跑通全链路后切飞书 | 用户指定优先级 |
| 多班级 | v1 单教师多班级（stu_profile.class_name） | 用户指定 |
| License | MIT | 自研组件 |

## 7. 数据安全（硬性）

- 仓库只含空框架 + Mock 数据；真实学员数据目录 `.gitignore`。
- API/Skill B 只读。
